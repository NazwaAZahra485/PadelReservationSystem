# Padel Reservation System - Tugas Besar Pemrograman Terapan
Project ini mengenai website reservasi lapangan padel.
User Role:
- Kustomer: Dapat booking lapangan padel dan mengikuti event tanpa harus melakukan login. 
- Owner: Dapat mengubah dan menghapus data lapangan dan event.
     - Jika ingin menambah lapangan baru, owner harus mengajukan penambahan lapangan baru ke admin.
     - Owner dapat memberi approval atau me-reject pembayaran yang dilakukan kustomer ketika kustomer booking atau reservasi event.
- Admin: Dapat memberi approval mengenai penambahan lapangan baru dan melihat laporan data booking lapangan.
